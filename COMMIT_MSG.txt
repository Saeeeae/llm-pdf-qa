feat: 8-module RAG-LLM monorepo restructure + Phase A/B production hardening

## Summary

Restructure legacy single-app codebase into 8 independent microservices (M1~M8)
with contract-first OpenAPI specs, per-module Makefiles, and full CI/CD + observability.
Phase A applied 12 critical security patches; Phase B implemented M3/M4 from stub to
production, added E2E tests, GitHub Actions, infra hardening, and load testing stack.

## Module Structure

- M1 identity: JWT auth, RBAC, MySQL HR sync (asyncmy + APScheduler)
- M2 doc-to-md: kordoc parser, daily 02:00 cron, Redis lock + DLQ
- M3 chunk-embed: BAAI/bge-m3, pgvector ivfflat + tsvector GIN
- M4 rag: Hybrid search (vector + BM25 RRF) + vLLM SSE streaming
- M5 gateway: JWT, rate limit, circuit breaker, /metrics protected
- M6 ui: Next.js 14 chat UI with SSE + rehype-sanitize
- M7 admin: Backend (FastAPI) + Frontend (Next.js dashboard)
- M8 web-search: External search with DLP + SSRF blocking

## Phase A — Critical Patches (12)

- SQL injection removal (text(f'...') → named bindparam)
- JWT_SECRET 32-char enforcement (no default)
- /metrics Basic Auth + Authorization header strip
- rehype-sanitize + safeHref URL validation
- SSRF block (private IP / metadata service)
- WebSocket JWT verification + impersonate perms
- M1 refresh race fix + password upgrade persistence
- shared-py async engine singleton (pool 20+40)
- DEV_AUTH production build block

## Phase B — Production Implementation

- B1 M2: Redis distributed lock, DLQ, /ingest background tasks,
        path traversal/symlink block, M3 retry, Prometheus metrics
- B2 M3/M4: dynamic batch size, idempotency, RRF env weights,
           Redis session history, vLLM circuit breaker
- B3 E2E: testcontainers chain tests, schemathesis contract lock
- B4 CI/CD: GitHub Actions (lint+test+contracts-diff+image-build+pr-checks)
- B5 Infra: healthcheck/depends_on, docker secrets, backup automation,
           1/4 GPU allocation, audit log centralization
- B6 Observability: Prometheus + Grafana + Loki + Promtail + Alertmanager,
                   locust load scenarios (100u / 200qpm sustained 30min)
